## Repository structure

The repository is organised into two main areas:

1. Python Fundamentals — independent study notebooks, scripts and small projects that cover core Python concepts and intermediate topics.
2. SMIT Class Work — lecture notebooks and assignments from the SMIT AI & Data Science course, organised by topic.

### Why this repo
- Keep study notes, examples, and assignments in one place.
- Reusable notebooks for learning, teaching, and quick reference.

## Folder overview

- `Python-Fundamentals/` — exercises and small projects (variables, data structures, control flow, functions, OOP).
- `SMIT-Class/` — course materials (Python basics, NumPy, Pandas) and assignment notebooks.

## Getting started

Prerequisites
- Python 3.8+ recommended
- Jupyter Notebook or JupyterLab

Install required Python packages (recommended inside a virtual environment):

```bash
pip install --upgrade pip
pip install numpy pandas pillow openpyxl
```

## Running notebooks locally

1. Clone the repository:

```bash
git clone https://github.com/Shahzaib695/Ai-Data-Science.git
cd Ai-Data-Science
```

2. Start Jupyter:

```bash
jupyter notebook
# or
jupyter lab
```

Open any `.ipynb` file in the browser to run or inspect the notebook.

## Notes on content
- Notebooks often include dataset references (CSV/Excel). If a notebook depends on a dataset not included here, check the notebook top cells for download instructions or comments.
- Assignment notebooks are kept at the root of the `SMIT-Class` folder to preserve external submission links.

## Contributing
- This repository is primarily a personal study collection. If you find an issue or have suggestions (typos, improved examples), open an issue or submit a pull request.
- When contributing notebooks, keep outputs cleared where possible to keep repository size small (`Kernel -> Restart & Clear Output`).
